06 — Reference

Lookup, never read in order — exit codes, flags, every guard in a line, conf keys, files

Every refusal in the system prints its own reason in the log; this page is the fast index
1

Exit codes

0nothing needs attention
1something does — a CT skipped, a round not clean, DR leftovers
2refused before touching anything

A filter that matches no row never exits 0. rsync: 0 and 24 are success, 23 once is the snapshot transient (twice is a damaged image), 11 is out of space (the engine grows the image and retries).

2

One flag set

--all / --ctidscope — always the real id; a bare verb refuses
--dry-runevery guard runs, nothing is written
--listread-only: who is where, what is left
--storageone lane (what cron uses)
--finalthe cutover round — recall needs the 9xxx stopped, failback needs PAUSE
--destroyremove the 9xxx for good = release R13; only after checking the real one
--to / --dstoverride fleet.tsv's placement (distribute)
--nodewhole machine, not per CT (evacuate, restore)
--digestmail doctor's report (watch)
--testsend a proof mail to KS_MAIL_INFRA after setup (mail-setup)
-h / --helpusage - never asked about, never runs anything (every verb)
-yskips the question and nothing else; there is no --force
3

Every guard, one line

Full reasoning lives in CLAUDE.md and ../decisions.md.

G1-G8migrate: pool off the root fs and mounted; never onto a running CT; unmount before resize; grow on ENOSPC; config only after a good sync, never overwritten; target id free cluster-wide; the source's net lines land on the island bridge, verified uplink-free on the NEW node before any transfer (go-live is a bridge swap)
R1-R14replica: snapshot+clone source; never into a running copy; dest mounted; target id free everywhere; config written then read back; ro,noload mounts; per-lane and per-copy locks; copy config must match the row; the mock bridge has no uplink; a stopped copy off production bridges; a dead source storage is one fact; a live 9xxx freezes that copy (R13); the copy is locked where it lives (R14)
B0-B8failback: production stopped (unreachable is not stopped); B2 lifecycle; image on a real mount and already existing; unmount before resize; grow on ENOSPC; --final refuses without its safety snapshot (B7); R14 again (B8)
D1-D8distribute: production cannot answer and cannot boot itself — one exception, every veth verified on the dead-end bridge from the kernel; source copy exists and is stopped; 9xxx free everywhere; dest active, off the root fs, space checked first; config after a good transfer; nothing started; the 9xxx locked on the target (D8)
C1-C8recall: the 9xxx found by asking the cluster; stopped for --final; direction from the provenance marker, never timestamps (C3); dest mounted; the right mount for the CT's state; nothing started, stopped or destroyed; both ends locked, 9 then 8
P/E/Kprepare: storage provably dead or nothing happens (P2/E2); the island bridge verified before use (P4); the origin record never overwritten (P5); a CT that will not stop is isolated, not forced (E4); cleanup needs failback's own state as proof (K2) and never stops a serving 9xxx before the real one is up (K3)

Conf keys

conf/ketsync.confKS_ROLE (master/slave, human-edited only), KS_MASTER_IP, KS_MAIL_FROM/_INFRA/_NODE/_DIGEST (watch refuses without them; a SLAVE watch needs only FROM+INFRA), KS_MASTER_TRIES/_GAP (3/5 - how hard a slave asks before it believes the master is gone), KS_WATCH_HEALTHCHECK (optional dead-man; green runs only), KS_MAIL_RELAY/_USER/_KEYFILE (the transport: `ketsync mail-setup` reads these three and points postfix at the relay - changing provider is an edit plus a re-run)
conf/ctrep.confBKP_SSH (root@backup-ip — the artery), BW_TOTAL_MB (per-machine ceiling, split per lane), OFFSET / DR_OFFSET (300 → 8300 / 9300), MOCKNET_BRIDGE (vmbr99), SHUTDOWN_GRACE
conf/ctmig.confthe migrate-side twin; its BW ceiling is separate (doctor nags until the conf merge lands)

Which file is what

conf/nodes.tsvip + role, every machine; no name column on purpose
conf/fleet.tsvthe DR map: ct, home, dr, dst — all required
conf/nodes.mapip → PVE node name, GENERATED — never hand-edited
inventory/inventory-replica.tsvthe nightly work list (replica + failback)
inventory/inventory-migrate.tsvthe intake work list, used while migrating
engines/PAUSE · engines/pause/<ctid>stop everything (failback windows) · pause one CT
logs/ · state/watch.tsvdaily logs, self-pruned · what watch holds raised

.sample files are the tracked examples; copy and drop the suffix. The real ones are per-site and never overwritten by git.
